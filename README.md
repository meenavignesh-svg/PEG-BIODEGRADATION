# BioHub — PEG Biodegradation Prototype

**SIH 2026 · Clean & Green Technology**  
**Team:** Marge Organics

Interactive conceptual systems model demonstrating a proposed pathway for **polyethylene glycol (PEG)** biodegradation using a biochar–hydrogel immobilization matrix and a coordinated microbial consortium.

> This is a **conceptual visualization prototype** for Smart India Hackathon 2026. It is not a validated industrial operating protocol.

## Process Flow

| Stage | Component | Role |
|-------|-----------|------|
| **01** | Polymer Feed | PEG-rich waste stream enters the treatment train |
| **02** | Biochar–Hydrogel Matrix | High-surface-area immobilization & support platform |
| **03** | Microbial Consortium | Biological core performing coordinated degradation |
| **04** | Degradation Pathway | Polymer → oligomers → intermediates → metabolites |
| **05** | Treated Stream | Conceptual mineralization endpoint |

### Microbial Consortium

| Organism | Primary Role |
|----------|--------------|
| *Ideonella sakaiensis* | Depolymerization |
| *Pseudomonas putida* | Intermediate utilization |
| *Bacillus subtilis* | Biofilm formation & enzyme support |

## Features

- Smooth staged animation with progressive node activation
- Continuous energy-flow visualization along the process train
- Live process monitor with status updates and progress bar
- Click-to-focus any stage when simulation is idle
- Fully responsive layout (desktop / tablet / mobile)
- Premium dark theme with glassmorphism and glow effects

## Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, animations, responsive grid/flex

Lightweight and dependency-free for fast loading and easy demonstration.

## How to Run Locally

```bash
# Clone the repository
git clone https://github.com/meenavignesh-svg/PEG-BIODEGRADATION.git
cd PEG-BIODEGRADATION

# Open in browser (any static server or simply double-click index.html)
# or use a local server:
python -m http.server 8000
# then visit http://localhost:8000
```
